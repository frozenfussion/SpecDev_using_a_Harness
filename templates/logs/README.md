# Logs

Every session READS these first and APPENDS as it goes. Never rewrite history. Newest entry at the bottom.
No passwords, tokens or keys in any of these files.

| File | Its one job |
|---|---|
| SESSION_LOG.md | What happened, in order, with times |
| DECISIONS.md | What was agreed, why, and by whom. A logged decision is not re-argued unless the owner reopens it |
| OPEN_QUESTIONS.md | Only questions that block real work |
| JOURNAL.md | Mistakes, corrections and the lesson from each |
| HANDOVER-<n>.md | What the next session needs to start cold |
| HANDOVER-<n>-PROMPT.md | The message that starts the next session |
